# Patrick Konermann – research homepage

Source of https://patrick-konermann.github.io, built with Jekyll on the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

- `_pages/about.md` – landing page
- `_publications/` – publications (`category: manuscripts`) and working papers (`category: conferences`)
- `_data/navigation.yml` – top menu
- `_config.yml` – site and author settings
